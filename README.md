# Untis 2.0

Удобный клиент для WebUntis: открывается мгновенно, сразу показывает отмены и замены, собирает домашки и контрольные в одном месте и даёт вести свои оценки. Это веб-приложение (PWA): его можно поставить на телефон как обычное приложение.

> Неофициальный проект. WebUntis — продукт Untis GmbH, данные берутся из твоего школьного аккаунта.

## Что умеет

- **Расписание.** На телефоне вид по дням (листается свайпом), на компьютере вся неделя сеткой. Отмены, замены, смена кабинета и дополнительные уроки выделены цветом. Сдвоенные уроки склеиваются, перемены и окна подписаны.
- **«Сейчас / дальше».** Какой урок идёт, в каком кабинете, сколько минут до конца и что следующее.
- **Задания.** Домашки из WebUntis плюс свои задачи. Их можно отмечать сделанными, просроченные собраны отдельно.
- **Контрольные.** Список с обратным отсчётом, а в расписании у урока появляется метка «Контрольная».
- **Оценки.** Вводишь сам, приложение считает взвешенное среднее по предметам и общее. Системы: Германия 1–6, Австрия 1–5, баллы 0–15, пятибалльная.
- Светлая и тёмная тема, русский, немецкий и английский. Работает офлайн: показывает последние сохранённые данные.

## Запуск локально

Нужен Node.js 20.19+ (лучше 22).

```bash
npm install
npm run dev
```

Открой http://localhost:5173 и нажми «Посмотреть демо»: это фейковая школа, логин не нужен. Чтобы войти по-настоящему, найди свою школу по названию и введи логин WebUntis.

Тесты и проверка типов:

```bash
npm test
npm run typecheck
```

## Как это устроено

```
shared/   типы и чистые функции (даты, склейка уроков), общие для сервера и фронта
server/   Node + Hono: прокси к WebUntis, сессии, кэш, демо-школа
  untis/  клиент WebUntis (JSON-RPC + внутренний REST) и нормализация данных
src/      React-приложение (Vite, PWA)
tests/    unit-тесты и тесты API против фейкового WebUntis
```

Браузер не может обращаться к WebUntis напрямую (CORS), поэтому все запросы идут через небольшой сервер:

- **Вход.** Сервер проверяет логин в WebUntis и кладёт данные входа в **зашифрованную httpOnly-cookie** (AES-256-GCM, ключ `SESSION_SECRET`) на устройстве пользователя. Базы с паролями нет.
- **Сессии WebUntis.** Сервер держит их в памяти и сам перелогинивается, когда WebUntis их сбрасывает.
- **Кэш.** Ответы кэшируются на минуту, сетка уроков и каникулы на 12 часов, чтобы не долбить WebUntis.
- **Защита от SSRF.** Сервер ходит только на `*.webuntis.com`.
- **Где хранятся оценки и свои задания.** Только в `localStorage` на устройстве. В настройках можно сохранить копию в файл и загрузить её на другом устройстве.

## Деплой

Нужен любой хостинг с Node.js: Render, Railway, Fly.io, свой VPS. Для PWA и защищённых cookie обязателен HTTPS.

```bash
npm ci
npm run build
SESSION_SECRET="$(openssl rand -base64 32)" npm start   # порт 3000, или задай PORT
```

`SESSION_SECRET` должен быть постоянным: если его сменить, всех разлогинит. Пример переменных лежит в `.env.example`.

## Ограничения

- У WebUntis нет публичного API. Используются те же интерфейсы, что у официальных приложений, и Untis может их поменять.
- Некоторые школы отключают доступ к домашкам или контрольным. Тогда эти разделы будут пустыми.
- Аккаунты родителей и учителей пока не поддерживаются, только ученические.
